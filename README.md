📱 **2° semestre - Programação de Aplicativos | Curso Técnico em Sistemas de Desenvolvimento do SENAI**

Este repositório reúne os códigos e projetos que desenvolvi nas aulas de *Frontend* com **ReactJS**, **Progressive Web Apps (PWA)** e na implementação de operações de **CRUD de clientes** da disciplina de Programação de Aplicativos.

Atualmente, curso o Técnico em Sistemas de Desenvolvimento no SENAI, onde aplico na prática conceitos de aplicações web modernas  desde a base estrutural com ReactJS e o gerenciamento de cadastros até a transformação em um PWA totalmente instalável.

---

🎯 **Sobre o projeto**

Este espaço foi criado para acompanhar a minha evolução prática na programação, registrando o passo a passo na construção de aplicações web modernas, manipulação de dados via CRUD e aplicando as melhores práticas de desenvolvimento *frontend* aprendidas em aula.

---

🚀 **Tecnologias utilizadas**

* **ReactJS**
* **Vite**
* **JavaScript / TypeScript**
* **HTML5**
* **CSS3**
* **Progressive Web Apps (PWA)**
* **Operações de CRUD (Cadastro, Consulta, Edição e Exclusão)**
