📱 2° semestre - Programação de Aplicativos | Curso Técnico em Sistemas de Desenvolvimento do SENAI

Este repositório reúne os códigos e projetos que desenvolvi nas aulas de Frontend com ReactJS e Progressive Web Apps (PWA) da disciplina de Programação de Aplicativos.

Atualmente, curso o Técnico em Sistemas de Desenvolvimento no SENAI, onde aplico na prática conceitos de aplicações web modernas — desde a base estrutural com ReactJS até a transformação em um PWA totalmente instalável.

🎯 Sobre o projeto

Este espaço foi criado para acompanhar a minha evolução prática na programação, registrando o passo a passo na construção de aplicações web modernas e aplicando as melhores práticas de desenvolvimento frontend aprendidas em aula.
